# Dust Sweeper - UX simplificada

Para testar, use TESTAR.bat na pasta principal do pacote. Nao copie arquivos por cima do projeto original.

A ferramenta cria outra pasta no seu computador, preserva as configuracoes e tenta instalar e validar o projeto antes de abrir o navegador. Nenhum deploy ou commit e executado.

Mudancas principais: formulario de scan na primeira tela; outras ferramentas em segundo plano; resultados compactos; filtros funcionais; selecao com foco na recuperacao; taxas claras antes da confirmacao; estados reais do widget; preservacao da origem das campanhas. Sem valor recuperavel inventado, sem limite minimo arbitrario e sem mudancas nas taxas.

Detalhes da validacao estao em docs/VALIDACAO.md. A medicao detalhada do Apps Script fica para outra etapa; este pacote nao pede mudancas na planilha.
